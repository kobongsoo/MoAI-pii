moaipii 연동 설명서
— Python · Rust · Java · PHP · C++

한국어 개인정보 검출 라이브러리 moaipii.dll / libmoaipii.so를 각 언어에서 불러 쓰는 방법입니다. 모든 언어가 같은 C 함수를 부르므로 결과도 같습니다. 다른 점은 좌표를 세는 단위뿐입니다.

01

묶음 구성

moaipii-<버전>-<플랫폼>/
├─ lib/        moaipii.dll · moaipii.dll.lib(Windows, C++ 링크용) · mp.exe   또는   libmoaipii.so · mp
├─ include/    moaipii.h (C) · moaipii.hpp (C++)
├─ bindings/   python/moaipii.py · rust/moaipii_dyn.rs · java/moaipii/*.java · php/MoaiPii.php
├─ doc/        이 설명서
└─ VERSION · CHANGELOG.md · README.md · SHA256SUMS

라이브러리는 다른 .so·.dll에 기대지 않습니다. 파일 하나만 옮기면 됩니다. 감싸개는 모두 환경변수 MOAIPII_LIB(파일 또는 폴더)로 위치를 알려 줄 수 있습니다.

02

좌표 단위 — 가장 중요한 것

결과의 start·end는 [start, end)입니다. 단위는 옵션 offsets로 고르며, 감싸개마다 자기 언어에 맞는 기본값을 씁니다.

// 본문: "홍길동 😀 010-1234-5678"   ← 이모지는 코드포인트 1 = UTF-16 2 = UTF-8 4바이트
offsets   start  end   자르기
char        6     19   Python  text[6:19]
utf16       7     20   Java    text.substring(7, 20)
byte       15     28   PHP     substr($text, 15, 13)   ·  C++  text.substr(15, 13)
주의

단위를 섞으면 오류 없이 엉뚱한 자리를 지웁니다. 기본값을 바꿀 때는 자르는 함수도 함께 바꾸세요. 마스킹할 때는 위치가 밀리지 않도록 뒤에서부터 바꿉니다.

04

언어별 사용

Python (3.8+, 표준 라이브러리만)

import moaipii                                   # bindings/python/moaipii.py 를 복사
r = moaipii.scan(text, ["RRN", "PHONE"])            # 좌표 char → text[s:e]
for it in reversed(r["items"]):
    text = text[:it["start"]] + "***" + text[it["end"]:]

ctypes 호출 중에는 GIL이 풀리므로, 여러 스레드에서 부르면 실제로 병렬로 돕니다. PyInstaller로 묶을 때는 DLL을 묶음 최상위(_MEIPASS)에 두면 찾습니다.

Rust (libloading 0.8 · serde_json 1)

let pii = MoaiPii::find_and_load(None, "MOAIPII_LIB")?;          // bindings/rust/moaipii_dyn.rs
let r = pii.scan(text, &labels, &ScanOpts::default())?;            // 좌표 char

Java (8+, JNA 5.14)

MoaiPii pii = MoaiPii.load();                                     // MOAIPII_LIB → -Dmoaipii.lib → ./lib → ./ → 시스템
MoaiPii.Result r = pii.scan(text, Arrays.asList("RRN", "PHONE"));     // 좌표 utf16 → substring

64비트 JVM이 필요합니다(size_t를 long으로 받습니다). scanBytes는 넘긴 byte[]를 호출이 끝나면 0으로 지웁니다.

PHP (7.4+, FFI)

require 'MoaiPii.php';
$pii = MoaiPii::load();
$r   = $pii->scan($text, ['RRN', 'PHONE']);                          // 좌표 byte → substr
  • CLI는 extension=ffi만 켜면 됩니다. 웹(php-fpm·Apache)은 ffi.enable=true 또는 opcache.preload가 필요합니다.
  • 감싸개 기본값은 invalid_utf8: "replace"입니다. EUC-KR 본문은 먼저 mb_convert_encoding($s, 'UTF-8', 'EUC-KR')로 바꿔서 넘기세요.

C++ (17, 헤더 하나)

// 링크형(기본)
//   Windows: cl /std:c++17 /EHsc /utf-8 app.cpp /I include lib\moaipii.dll.lib
//   Linux  : g++ -std=c++17 app.cpp -I include -L lib -lmoaipii -Wl,-rpath,'$ORIGIN'
// 동적 로드형: #define MOAIPII_DYNAMIC 을 include 앞에 (Linux 는 -ldl)
#include "moaipii.hpp"
auto pii = moaipii::Lib::load();
auto r   = pii.scan(text, {"RRN", "PHONE"});                           // 좌표 byte → substr

CentOS 7의 기본 g++(4.8)은 C++17을 못 합니다. devtoolset의 g++를 쓰세요.

05

안전 규칙

  • 본문은 (포인터, 길이)로 넘깁니다. 본문 속 \0에서 잘리지 않습니다.
  • 원문 값은 요청할 때만(values:true) 경계를 넘습니다. 라이브러리는 결과 문자열을 해제할 때 0으로 덮고, 로그를 남기지 않습니다.
  • 스레드: 라이브러리에 전역 상태가 없습니다. 한 번 불러온 객체를 여러 스레드가 함께 써도 됩니다.
  • 판 확인: 감싸개는 불러온 직후 moaipii_abi_version()을 비교하고, 다르면 abi 오류를 냅니다.
